# 🖍 螢光筆暴走 Highlighter Gone Wild

給華語老師的上課白板。學生說話時直接打字，系統即時顯示拼音或注音；用四種顏色的螢光筆標記，點一下字詞就能查字典；下課後匯出整理好的 PDF 給學生。

A class whiteboard for Mandarin teachers: type while the student talks and pinyin / 注音 appear as you type. Mark words with four highlighter colours, click a word for the dictionary, and export a tidy PDF for the student after class.

**👉 開始使用 Open it:** https://bluenihaoah.github.io/highlighter-gone-wild/

## 功能 Features

- **即時拼音／注音**：可以切換 Off／Pinyin／注音、繁／簡、字的大小
- **螢光筆四色**：🟩 新生詞 New word · 🟥 發音加強 Pronunciation · 🟦 舊生詞忘記 Forgot · 🟨 一般畫記 Highlight（可以寫老師的說明）
- **三個小規則**：`[ ]` 放錯位置 · `( )` 可以忽略（PDF 顯示淺灰）· `機場 airport` 中文後面打英文就是新生詞
- **點詞查字典**：拼音、注音、英文解釋、朗讀
- **匯出 PDF**：依顏色分成表格＋今日筆記，檔名是「日期 學生名字」，可以加上你的署名
- **自訂規則**：螢光筆的名稱、顏色、數量（最多 6 種）；自己的符號規則（例如 `{ }` 標成紅色刪除線）；PDF 要放哪些表格、標題。規則可以匯出成檔案分享給別的老師
- **學生模式**：不用學生／只輸入名字／完整學生資料（可依學生時區算日期）

## 資料存在哪裡 Where your data is kept

這個網頁版的資料只存在**你自己的瀏覽器**裡，不會上傳到任何地方。換電腦或清除瀏覽器資料前，請到 ⚙ 設定 → 下載備份。

Everything stays in **your own browser**; nothing is uploaded. Use ⚙ Settings → Backup before changing computers or clearing browser data.

claude.ai 版本可以跨裝置同步，還能用 Claude 依句子挑英文意思、依學生生活寫例句。 A claude.ai version also syncs across devices and uses Claude for context-aware meanings and example sentences.
